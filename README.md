# Aston Martin Linux (AML OS)
## Vanquish Linux Edition

Este projeto é uma simulação de alta fidelidade de um Desktop Environment Linux de luxo.

<!-- W1_DISTRIBUICAO_INICIO -->
## Distribuição e acesso

O W1.OS é um ambiente de desktop simulado, desenvolvido como projeto web. Não é uma distribuição Linux nem possui ISO ou executável Windows publicado. Consulte os produtos comerciais e seus instaladores na [Central de Apps W1](https://github.com/W1CAPITAL/Central-de-Apps).

[Consultar versões e downloads](https://github.com/W1CAPITAL/Central-de-Apps/releases) · [Catálogo completo W1](https://github.com/W1CAPITAL/Central-de-Apps/blob/main/docs/ECOSSISTEMA-W1.md)

Os arquivos da série `preview-v0.1.48` são versões de teste, não instaladores oficiais assinados para atualização automática.

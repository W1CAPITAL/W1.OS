# Aston Martin Linux (AML OS)
## Vanquish Linux Edition

Este projeto é uma simulação de alta fidelidade de um Desktop Environment Linux de luxo.

### Tecnologias
- Next.js 15
- Tailwind CSS
- Framer Motion
- Zustand

### Características
- Gerenciador de Janelas real (arrastar/redimensionar)
- Navegador, Terminal e Loja de Apps funcionais
- Estética Carbon Fiber & Racing Green
